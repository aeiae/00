📥 导入浏览器书签

支持从 Chrome / Edge / Firefox / Safari 等浏览器导出的 HTML 书签文件（Netscape Bookmark 格式）。将正确识别文件夹层级。

📤 导出书签

导出为浏览器可识别的 HTML 书签文件，可直接导入到任何浏览器。

📥 从 JSON 恢复

从之前导出的 JSON 备份文件恢复书签。

☁️ GitHub 书签同步

使用 GitHub Gist 实现跨设备书签同步。请填写以下信息，保存后每次打开页面将自动从云端加载书签。

🔑 GitHub 配置

前往 GitHub Token 设置 创建，勾选 gist 权限
创建后会自动填入 Gist ID，用于后续同步
